الأسئلة الشائعة

إجابات حول التكاملات والبيانات التجريبية

هل التكاملات المعروضة متصلة فعليًا؟
لا. جميع التكاملات الموضحة هي بيانات تجريبية ثابتة. البطاقات التي تظهر "متصل (تجريبي)" لا تعني وجود اتصال حقيقي بأي API خارجي. هذه الصفحة واجهة أمامية فقط لعرض مثال على ما ستبدو عليه لوحة التكاملات عند الربط بخادم حقيقي.
هل يمكن استخدام Travelpayouts لاحقًا؟
نعم، هذه الصفحة قابلة للربط لاحقاً. عند تطوير الخادم يمكن تفعيل Travelpayouts عبر إدخال Marker ID وAPI Token الحقيقيين. ستُحفظ البيانات على الخادم ويبدأ الاتصال الفعلي. حقول الإعداد الموضحة مثال على ما سيحتاجه المطور.
هل يمكن ربط Amadeus أو Duffel؟
نعم، كلا الـ APIs جاهزان للربط. تظهر حالتهما "جاهز للربط" لأن هيكل البيانات والحقول المطلوبة معروف مسبقاً. عند الربط بخادم، يكفي تمرير API Key و Secret في حقول الإعداد الظاهرة لبدء الاتصال. بيئة Production في Amadeus معطّلة حتى الربط الفعلي.
هل يتم تشغيل Scraping الآن؟
لا يتم تشغيل أي Scraping فعلياً في هذه النسخة. بطاقات "Scraping Review" هي أدوات مراجعة يدوية فقط. أي محتوى يصل عبر مصدر خارجي يجب أن يمر بمراجعة يدوية قبل النشر. لا يُنشر أي كوبون أو عرض تلقائياً. المصادر ملزمة باحترام سياسة الموقع المصدر.
هل يتم إرسال رسائل WhatsApp أو Email؟
لا يتم إرسال أي رسائل حقيقية في هذه النسخة. حقل "Email متصل (تجريبي)" هو حالة افتراضية تجريبية. زر "اختبار" الموجود في بطاقات الإشعارات يُظهر رسالة تنبيه بأنه اختبار تجريبي فقط ولا يُرسَل فعلياً. عند الربط بخادم حقيقي سيتم الإرسال عبر مزود البريد أو WhatsApp API المُعدّ.
هل يتم نشر الكوبونات تلقائيًا عبر التكاملات؟
لا يتم نشر أي كوبون أو عرض تلقائياً. حتى في النظام الحقيقي، كل محتوى مستورد — سواء من Coupon API أو Affiliate Feed أو أي مصدر آخر — يجب أن يمر عبر سير العمل اليدوي (Manual Approval Workflow) ومراجعة يدوية كاملة قبل الظهور على الموقع. هذا القرار مبدئي ولا يمكن تجاوزه.
