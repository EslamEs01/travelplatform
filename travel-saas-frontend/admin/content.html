أسئلة شائعة

لا. جميع إجراءات النشر في هذه النسخة تجريبية فقط. لا يتم إرسال أي محتوى إلى خادم حقيقي أو تحديث الموقع العام. كل التغييرات تُعاد إلى وضعها الأصلي عند إعادة تحميل الصفحة.
نعم. تم تصميم الواجهة لتكون قابلة للربط مع أنظمة CMS كـ Contentful أو Strapi أو واجهة برمجية مخصصة. كل زر إجراء يحمل `data-ct-action` و`data-content-id` جاهزَين للربط بنقاط API المستقبلية.
لا. تبديل التمييز يُغيّر الحالة المرئية في هذه الواجهة فقط (جلسة المتصفح الحالية) ولا يؤثر على الصفحة الرئيسية العامة. في البيئة الإنتاجية، سيتم ربط هذا الإجراء بـ API يحدّث ترتيب العرض على الموقع فعليًا.
يظهر المحتوى المستورد أو المقدم من شركاء في تبويب "بانتظار المراجعة" مع سبب الإحالة. المشرف يراجع كل طلب ثم يختار القبول أو الرفض يدويًا. لا يتم نشر أي محتوى تلقائيًا دون مراجعة بشرية — حتى في النسخة الإنتاجية.
لا. جميع عمليات الحذف تجريبية. لا يُرسَل أي طلب إلى قاعدة البيانات في هذه النسخة. يُعرض مربع تأكيد قبل أي حذف لمنع الأخطاء العرضية، وبعد التأكيد يظهر إشعار مؤقت فقط دون أي حذف فعلي.
أقسام الصفحة الرئيسية تتحكم في هيكل وترتيب كتل عرض الصفحة العامة (البانر، العروض، الوجهات…). أما الوجهات والمقالات والعروض والكوبونات فهي محتوى المنصة الفعلي. يمكن تمييز أي عنصر من المحتوى ليظهر داخل القسم المناسب في الصفحة الرئيسية.
