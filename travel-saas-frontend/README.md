# Travel SaaS Platform — Frontend Foundation

Arabic-RTL, mobile-first static frontend built with HTML5 + local Tailwind CSS v3.4 + vanilla JS.
No framework. No CDN at runtime.

---

## Quick Start

```bash
# 1 — Install (build-time only; Node 18+ required)
npm install

# 2 — Build compiled CSS
npm run build       # one-shot → assets/css/tailwind.css
npm run watch       # incremental during development

# 3 — Preview in browser (recommended over file://)
npm run serve       # starts static server at http://localhost:3000
#  → open http://localhost:3000/pages/index.html

# 4 — Code quality
npm run format      # Prettier (HTML, CSS, JS)
npm run lint:css    # Stylelint → src/**/*.css

# 5 — Accessibility audit (requires running server)
npm run audit:a11y  # axe-core → pages/index.html
```

├── partials/                 # canonical shell snippets → future Django {% include %}

│   └── footer.html           # trust row + nav + social + copyright

> `assets/css/tailwind.css` is generated by `npm run build` and is gitignored.
> Every page links it as a local stylesheet — **zero external CDN requests at runtime**.

## Interaction Utilities (`window.TUI`)

All interactions are in `src/js/ui.js`, wired declaratively via `data-*` in `src/js/main.js`.

```js
TUI.toast(msg, { type, duration, dismissible }); // info | success | error | warning
TUI.modal.open(id, { onClose }) / TUI.modal.close(id);
TUI.drawer.open(id) / TUI.drawer.close(id) / TUI.drawer.toggle(id);
TUI.validateForm(formEl, { rules }); // → { valid, errors }
TUI.copyToClipboard(text); // → Promise<boolean>
```

| Attribute                              | Effect                              |
| -------------------------------------- | ----------------------------------- |
| `data-coming-soon`                     | Prevent navigation; show info toast |
| `data-drawer-open="id"`                | Open drawer                         |
| `data-drawer-close`                    | Close nearest drawer                |
| `data-modal-open="id"`                 | Open modal                          |
| `data-modal-close`                     | Close nearest modal                 |
| `data-copy="text"`                     | Copy text → toast                   |
| `data-toast="msg"` + `data-toast-type` | Show toast on click                 |
| `data-validate` on `<form>`            | Inline validation on submit         |
| `data-year`                            | Replaced with current year          |
